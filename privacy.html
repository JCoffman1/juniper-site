Juniper privacy policy

Effective 26 October 2026

Who uses Juniper

Juniper is a private assistant used only by its owner, Jess Coffman (JC Digital Strategies). It is not offered to the public.

What Google data it accesses

With the owner's permission, Juniper reads events from the owner's own Google Calendar accounts (read-only). If the owner later connects Gmail, Juniper reads the owner's own email for the same purpose. It does not access anyone else's account.

How the data is used

  • Only to answer the owner's own questions and prepare her daily summary.
  • To produce an answer, the relevant text is processed by the Claude AI service (Anthropic) under its API terms.
  • It is never sold, never used for advertising, and never shared with anyone else.

Where it is stored

Sign-in credentials and any saved notes stay on the owner's own computer. Calendar and email content is fetched when needed and is not stored on any server run by Juniper.

Google API Services User Data Policy

Juniper's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be withdrawn at any time at myaccount.google.com/connections.
